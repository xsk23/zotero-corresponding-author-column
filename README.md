# Corresponding Author Pro (通讯作者极速版) for Zotero

这是一个专为 Zotero 7 及以上版本（完美兼容 Zotero 9 开发版）设计的文献管理辅助插件。

在集成电路 (IC)、计算机、物理等众多理工科领域，论文的**最后一位作者**通常是课题组负责人（PI）即通讯作者。然而，目前主流的外部 API（如 Crossref, OpenAlex）常常错误地将第一作者或提交者标记为通讯作者。

本插件抛弃了缓慢且容易出错的联网抓取，采用**本地极速分析**，一键精准提取最后一位作者作为通讯作者，并在文献列表中单列显示，极大地方便了按课题组/导师进行文献分类和归档。

## ✨ 核心特性

- 🚀 **极速本地提取**：无需联网，瞬间处理成百上千篇文献，彻底告别 API 延迟和报错。
- 🎯 **精准锁定 PI**：完美契合学术惯例，自动提取文献的最后一位真正作者，并自动覆盖修正旧版本错误抓取的一作数据。
- 🀄 **中英文智能排版**：自动识别作者语言。中文作者智能拼接为“姓+名”（如：张三），英文作者拼接为“名+空格+姓”（如：John Doe）。
- 🧹 **智能清理**：自动清理 `其它 (Extra)` 字段中冗余的旧标记，保持元数据整洁。
- 📊 **专属列表视图**：在 Zotero 主界面提供独立的“通讯作者”列，支持点击表头一键排序，方便将同一个课题组的论文聚类整理。

## 📦 安装说明

1. 准备好打包好的 `.xpi` 插件文件。
2. 打开 Zotero，点击顶部菜单栏的 `工具 (Tools)` -> `附加组件/插件 (Add-ons)`。
3. 点击右上角的齿轮图标 ⚙️。
4. 选择 `Install Add-on From File... (从文件安装插件...)`。
5. 选择你的 `.xpi` 文件并确认安装。
6. **重启 Zotero** 使插件生效。

## 💡 使用方法

### 1. 显示“通讯作者”列
安装并重启 Zotero 后，在中间文献列表的表头（例如“标题”、“年份”所在的行）**点击右键**，在弹出的列选择菜单中，找到并勾选 **“通讯作者”**。

### 2. 一键批量提取
1. 在文献列表中选中你需要处理的文献（支持 `Ctrl+A` 批量全选）。
2. **右键点击**选中的文献。
3. 在右键菜单的底部选择 **“提取最后一位作者作为通讯作者 (极速版)”**。
4. 稍等片刻，弹窗提示完成后，对应的 PI 名字就会立刻显示在列表中。

### 3. 手动干预 (可选)
插件将提取到的信息保存在条目右侧的 `其它 (Extra)` 字段中。如果你需要对极个别文献进行手动修改，只需在 `其它 (Extra)` 字段中另起一行，按以下任意一种格式填写即可：

- `通讯作者: 张三`
- `通信作者: 张三`
- `Corresponding Author: John Doe`
- `Correspondence: John Doe`
- `CA: John Doe`
